# 🔐 WordThon — Login & Registration UI

A responsive **login and registration user interface** developed for **WordThon** using HTML, CSS, and JavaScript.

The project provides a clean front-end interface where users can switch between login and account creation forms, manage password visibility, and select their country and city through dynamic form controls.

> This project is a front-end UI prototype. It does not include backend authentication, database integration, or real social login functionality.

---

## ✨ Features

- Login interface
- User registration form
- Responsive layout
- Login and registration form switching
- Show and hide password functionality
- Country and city selection
- Dynamic city options based on the selected country
- Date of birth input
- Gender selection
- Social login interface
- Form validation using HTML input requirements

---

## 📝 Registration Form

The registration interface collects:

- First name
- Last name
- Date of birth
- Country
- City
- Gender
- Email
- Password
- Password confirmation

The available cities are dynamically updated using JavaScript based on the selected country.

## ⚙️ How It Works

The interface contains two main views:

**Login**

Users can enter their email and password and toggle password visibility.

**Create Account**

Users can enter their personal information and select a country. JavaScript dynamically updates the available cities based on the selected country.

Users can switch between both interfaces without leaving the page.

---

## 🚧 Project Scope

WordThon currently demonstrates the **front-end design and interaction flow** of a login and registration system.

The following functionality is not implemented:

- Backend authentication
- User database
- Account creation
- Password recovery
- Google authentication
- Facebook authentication
- Apple authentication

These elements are presented as part of the user interface only.
